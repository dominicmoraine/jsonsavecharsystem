This project is a Java program that creates video game characters and saves their information into JSON and XML files. It also reads both files and displays their contents in the console

## How to Run
1. Open the project in IntelliJ IDEA.
2. Run Main.java.
3. The program creates the JSON and XML files.
4. The console displays the contents of both files.

## What I Learned
This assignment helped me practice creating Java objects, using lists, and reading and writing files. I also learned how JSON and XML can store the same information in different formats.
